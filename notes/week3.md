# Week 3 학습노트

이미지의 픽셀 좌표를 실세계 좌표처럼 사용할 수 있도록 변환했다.

- 이미지 중앙이 원점이 되도록 먼저 좌표를 이동했다.
- 스케일 행렬로 픽셀 단위를 줄이고 회전 행렬로 축 방향을 바꿨다.
- 각도는 degree에서 radian으로 바꾼 뒤 `sin`, `cos`에 사용했다.
- 이동 → 스케일 → 회전 순서가 달라지면 결과도 달라졌다.
- 최근 좌표를 matplotlib으로 표시해서 변환 결과를 확인했다.

행렬식을 외우는 것보다 한 단계씩 좌표가 어떻게 바뀌는지 확인하는 것이 이해에 도움이 됐다.
