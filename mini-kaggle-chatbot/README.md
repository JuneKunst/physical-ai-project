# MoMA CSV 챗봇

MoMA 작품 데이터에서 제목, 작가, 재료와 작품 분류를 검색하는 챗봇입니다.

[Google Colab에서 노트북 열기](https://colab.research.google.com/github/JuneKunst/physical-ai-project/blob/main/mini-kaggle-chatbot/June_MoMA_CSV챗봇.ipynb)

- 노트북: `June_MoMA_CSV챗봇.ipynb`
- 데이터: `data/moma_artworks_sample.csv`
- 원본 데이터: [MoMA Collection](https://github.com/MuseumofModernArt/collection)

## 실행

1. 위 Colab 링크를 엽니다.
2. 위에서부터 셀을 차례로 실행합니다.
3. 마지막 셀에서 생성된 채팅 화면을 확인합니다.

검색 예시는 `rubber`, `초콜릿`, `neon`, `머리카락`, `machine`입니다.
